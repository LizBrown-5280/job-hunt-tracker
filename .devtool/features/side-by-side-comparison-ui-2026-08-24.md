# Side-by-Side Comparison UI

Build the basic reveal view for comparing a response with its model answer after the user has attempted a question.

## Acceptance Criteria

- [ ] Keep the model answer hidden until the user chooses to reveal it
- [ ] Show clear "Your Response" and "Model Answer" labels
- [ ] Use a stacked layout on narrow screens and a comparison layout on wider screens
- [ ] Ensure readable text wrapping and sufficient contrast
- [ ] Test reveal and responsive behavior in the MVP wizard

## Notes

This is part of the MVP flashcard loop. Difference highlighting, counts, and copy-to-clipboard can follow once the core flow is useful.
