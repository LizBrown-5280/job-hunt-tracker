# Build Job Board with Draggable Cards

Create a Kanban-style Job Board page showing applications as draggable cards organized by status.

## Acceptance Criteria

- [ ] Create JobBoard (or similar) landing page
- [ ] Display applications as cards grouped by status columns (Not Started, Applied, Interviews, Offers Made, Declined, Withdrawn, Rejected)
- [ ] Implement drag-and-drop to change application status
- [ ] Show key info per card: company, role, priority, next action, sentiment indicator
- [ ] Support filtering by cycle (Show Current vs Show All)
- [ ] Add quick-access actions (view detail, mark complete, etc.)
- [ ] Persist status changes back to the applications store

## Notes

Job Board is the dashboard/landing page for the application. Draggable cards provide visual status flow and quick triage.
